# ふたご回転 — HutagoEditor

**ふたご回転**（双子回転）のブラウザ版プレイ＆ステージエディタです。  
A と B の 2 体が連結線でつながった状態でステージを進み、ゴールを目指します。  
このリポジトリは開発・検証用のスタンドアロン HTML アプリで、ビルドやサーバーは不要です。

## 起動方法

1. リポジトリを clone またはダウンロードする
2. `index.html` をブラウザで開く

ローカルサーバー経由でも動作します（例）:

```bash
# Python 3
python -m http.server 8080

# Node.js (npx)
npx serve .
```

ブラウザで `http://localhost:8080` を開いてください。

## ゲームの概要

- **A**（青）と **B**（ピンク）が連結線で結ばれています
- どちらか一方が **軸** になり、もう一方が **周回** します
- **Q / E**（または相当する操作）で軸を切り替え、周回の向きを変えます
- 跳ね返り壁に当たると周回方向が反転します
- 即死ブロックや壁に触れるとゲームオーバー
- チェック柄の **ゴール** に到達するとクリア

### 操作（プレイ）

| 入力 | 左回り（軸切替） | 右回り（軸切替） | リスタート |
|------|------------------|------------------|------------|
| キーボード | `Q` | `E` | `R` |
| ゲームパッド | 十字キー `←` | 十字キー `→` | `X` ボタン |
| タッチ | 画面下「↺ 左」 | 画面下「右 ↻」 | 「再開」 |

- キャンバス上に表示される **Q / E** ボタンをタップしても軸切替できます
- 中間地点（CP）を通過すると記録され、`R` でそこから再開できます

## タイル一覧

| ID | 名称 | 説明 |
|----|------|------|
| 0 | 空 | 何もないマス |
| 1 | 跳ね返り壁 | 固体。周回側が当たると跳ね返る |
| 2 | 線即死 | **連結線**が触れると即死。縁は黒黄の縞、中央は水色の線 |
| 3 | ゴール | 白黒チェック柄。A または B が入るとクリア |
| 4 | スポーン配置 | エディタ専用。A / B の初期位置をドラッグで設定 |
| 5 | 中間P | 通過でチェックポイント記録 |
| 6 | 体即死 | **A / B 本体**が触れると即死。縁は黒黄の縞、中央に A/B マーク |

## 使い方

### プレイ

1. 画面上部の **プレイ** タブを選ぶ
2. **レベル** から組み込みステージを選択する
3. または **JSON読込** で自作ステージを読み込む
4. **エディタ** タブで編集中のステージは、プレイに戻るとそのまま試せます

### エディタ

1. **エディタ** タブを開く
2. パレットからタイルを選び、キャンバス上をドラッグして配置
3. **右ドラッグ** で消去（スマホは **消しゴム** トグル）
4. **ホイール** で縦スクロール、**Shift + ホイール** で横スクロール（スマホは **2 本指ドラッグ**）
5. **回転距離**・**回転速度**・**グリッド** を変更したら **適用**
6. **JSON出力** / **ファイル保存** でステージを書き出し

#### 主なパラメータ

| 項目 | 説明 | 既定値 |
|------|------|--------|
| 回転距離 (px) | A–B 間の周回半径 | 120 |
| 回転速度 (rad/s) | 周回の角速度 | 2.2 |
| グリッド | ステージの横×縦マス数 | 40 × 30 |

## レベル JSON 形式

エクスポートされる JSON は次の構造です。

```json
{
  "name": "ステージ名",
  "cols": 40,
  "rows": 30,
  "tiles": [0, 1, 2, ...],
  "orbitRadius": 120,
  "orbitSpeed": 2.2,
  "spawn": {
    "ax": 80,
    "ay": 200,
    "bx": 200,
    "by": 200
  },
  "checkpoint": { "x": 400, "y": 300 }
}
```

| フィールド | 型 | 説明 |
|------------|-----|------|
| `name` | string | ステージ名 |
| `cols` / `rows` | number | グリッドサイズ（マス数） |
| `tiles` | number[] | タイル ID の一次元配列（行優先: `row * cols + col`） |
| `orbitRadius` | number | 周回半径（40〜400） |
| `orbitSpeed` | number | 周回速度（0.5〜8） |
| `spawn` | object | A (`ax`, `ay`) と B (`bx`, `by`) の初期座標（px） |
| `checkpoint` | object \| null | 中間地点の中心座標。タイル ID 5 からも同期 |

1 マス = **32 px** です。

## 組み込みステージ

| 名前 | 内容 |
|------|------|
| チュートリアル | 基本操作の確認用 |
| 跳ね返り迷路 | 壁・中間P・即死ブロックを含む |
| 即死との距離 | 線即死・体即死を意識したステージ |

## プロジェクト構成

```
HutagoEditor/
├── index.html          # エントリポイント
├── css/
│   └── style.css       # UI・レスポンシブ
└── js/
    ├── main.js         # タブ切替・UI 連携
    ├── game.js         # ゲームループ・入力・描画
    ├── editor.js       # ステージエディタ
    ├── core/
    │   ├── tiles.js        # タイル定義・定数
    │   ├── tile-render.js  # タイル描画
    │   ├── collision.js    # 当たり判定・跳ね返り
    │   └── spawn.js        # スポーン配置
    └── levels/
        ├── level-data.js   # JSON 入出力・正規化
        └── builtin.js      # 組み込みステージ
```

## 技術メモ

- **Pure HTML / CSS / JavaScript**（フレームワーク・ビルド不要）
- Canvas 2D で描画
- ゲームパッド API 対応
- スマホ向けにタッチボタン・2 本指パン・safe-area 対応
